## 3. 通用约定（所有规范共用）

- **元信息头**：每篇 `.md` 首行起用 HTML 注释块记 `name` / `creator` / `created` / `modified`（各规范另有追加字段）。
- **默认创建人**：`Li Cheng`。
- **日期**：以会话上下文 currentDate 为准；`created` 创建后不变，每次实质修改刷新 `modified`。
